MOMENTS – iPHONE UPLOAD

1. Entpacke das ZIP in Dateien auf dem iPhone.
2. Lade alle Dateien aus diesem Ordner in das Hauptverzeichnis des GitHub-Repositories hoch. Keine Unterordner erforderlich.
3. GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Warte auf die Veröffentlichung und öffne https://p4zhpkmbmg-design.github.io/moments/ in Safari.
5. Teilen > Zum Home-Bildschirm.

Textpools: tease.json, day.json, evening-short.json, evening-medium.json, evening-long.json. Bearbeite die JSON-Dateien direkt auf GitHub. Jede Datei enthält ein Array aus Texten in Anführungszeichen, getrennt durch Kommas.

Hinweis: Alle Texte sind auf einer GitHub Pages-Website öffentlich abrufbar.
